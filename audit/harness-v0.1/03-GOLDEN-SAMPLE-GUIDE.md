# Golden Sample Review Guide

`samples/` 中的图片是 v0.1 **方向样板**，不是最终生产稿。

## 已验证的方向

### 首页 / Home

目标：

- Primary Visual Moment = 双猫 + 山景 / 艺术摄影主视觉
- Editorial typography
- UI 退后，内容与视觉主体前置
- 暗色、低饱和、暖灰 / 冷灰并存
- 猫作为角色，不变成“宠物网站”

### Project Detail

目标：

- Hero 和内容区有清晰空间关系
- 项目内容比组件更重要
- Gallery / Principles / Motion 等通过 editorial grid 而非 card stack 呈现

### Gallery

目标：

- 图片本身成为主要视觉语言
- Filters / metadata / Lightbox 低存在感
- 中英文可以共同存在
- Lightbox / detail 是 Shared Element Transition 的最佳 Golden Sample 场景

### Motion Board

目标：

- Shared Element Transition
- Character States
- Scroll Narrative
- Hover / Focus

不再把 Beam / Aurora / SVG Draw 当作 Motion Golden Sample。

## Review 标准

请针对每张图判断：

1. 是否“像 Fragrance”，而不是像 generic premium template？
2. 技术感是否过弱 / 过强？
3. 艺术馆 / 摄影杂志感是否过重？
4. 猫咪比例是否过高？
5. 中文排版是否自然？
6. 是否有可作为真正产品页面的结构，而不仅是概念图？
7. 哪一张可以升级为真正 Golden Sample？

## 推荐下一轮冻结的 Golden Types

```text
G01 Home
G02 Project Detail
G03 Gallery
G04 Article / Writing
G05 Motion — Gallery → Detail
G06 Motion — Character State
```
